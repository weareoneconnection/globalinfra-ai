# 阶段 9.1：参赛黄金主线与评测证据

## 1. 参赛定位

**GlobalInfra AI——面向海外交通基础设施项目的可信 AI 执行与运营数字孪生平台。**

本阶段不是增加一组静态宣传页面，而是把已经存在的通用接入、国家包、知识检索、多智能体、人工审批、可信执行和数字孪生能力编排为一条评委可以现场验证、开发者可以复现、CI 可以阻止回归的黄金主线。

AI 出海三个方向分别由以下系统证据支撑：

| 赛道方向 | 系统证据 |
| --- | --- |
| 工具出海 | 双语事件接入、国家/生命周期识别、跨国法规与工程证据、合同风险工作流 |
| 属地融合 | 马来西亚国家包、属地主管机关与许可关卡、HSE 培训、人工责任边界 |
| 能力输出 | 项目级运营数字孪生，统一输出 IFC、GLTF、3D Tiles、GeoJSON、WMS、IoT 六类接口 |

## 2. 七步黄金主线

入口：`/competition`

主场景采用完全合成的 `MY-RAIL-A` 马来西亚轨道项目与 `CASE-GOLDEN-MY-001` 高处作业业主通知：

1. **双语事件接入**：识别 HSE、CRITICAL、立即响应。
2. **国家与生命周期路由**：识别马来西亚、施工阶段并路由到 `MY-RAIL-A`。
3. **国家包应用**：展示国家包版本、许可关卡、主管机关和法律边界。
4. **知识证据检索**：真实运行 TF-IDF 检索与多智能体分析，引用知识库实际记录。
5. **数字孪生影响定位**：锚定稳定 Twin ID，同时展示 4D 进度、5D 成本和六类数据接口。
6. **多智能体计划与人工关卡**：HSE、合规、人力、规划、核验等运行记录可见；CRITICAL HSE 需要两项明确人工审批。
7. **可信执行与独立核验**：调用现有 `document.generate` 工具生成内容寻址草案，产生执行回执；独立核验审批关联、证据引用、输出契约与摘要后才允许关闭。

页面上的“确认人工审批并运行闭环”是显式的人机责任边界。生成物永远标记为 `DRAFT_ONLY_NOT_SENT`，`external_delivery_performed=false`，不会发送邮件或外部函件。

## 3. 评测证据

数据集：`services/api/evals/competition_outbound.jsonl`

共 30 条合成用例：

- 8 条多语现场事件；
- 8 条法规与许可问题；
- 6 条合同与索赔事件；
- 4 条属地 HSE 培训事件；
- 4 条数字孪生运营事件。

评测直接调用生产代码中的 `build_intake_result` 与 `KnowledgeIndex`，并使用数据库内已版本化的知识记录。它不是对数据集字段做静态检查。质量门禁覆盖：

- 国家识别准确率；
- 生命周期识别准确率；
- 风险和工单类型准确率；
- Top-3 证据召回率；
- 引用完整率；
- 无证据查询拒答率；
- 结构化输出有效率；
- 无模型条件下的确定性降级成功率；
- 单条平均墙钟延迟。

复现方式：

```bash
python evals/run_competition_eval.py
curl 'http://localhost:8001/competition/evaluation?include_cases=true'
```

CI 在每次 push / PR 上执行同一评测；任一门禁失败都会令 API job 失败。UI 中显示的数字也来自该实时评测函数，不存在单独维护的“宣传指标”。

## 4. 评审 100 分映射

| 评审部分 | 分值 | 可验证材料 |
| --- | ---: | --- |
| 创新性 | 30 | 国家感知多智能体可信执行、知识证据与运营数字孪生统一主线 |
| 实用性 | 30 | 30 条可执行评测、真实 API、明确阈值、回执与安全边界 |
| 方案完整性 | 40 | 一键参赛页、180 秒演示、国家包、开源数据集、CI 与复现命令 |

## 5. 录屏建议

建议 5 分钟内采用“30 秒问题与定位 + 180 秒产品演示 + 60 秒评测与部署证据 + 30 秒价值收口”：

1. 在 `/competition` 说明项目事件跨语言、跨法规、跨系统的问题。
2. 点击七步主线逐项解释证据；在最后点击“确认人工审批并运行闭环”。
3. 展示执行回执、独立核验六项检查和内容摘要。
4. 打开完整 JSON 评测证据，说明 30 条用例及 CI 门禁。
5. 跳转 `/showcase?project_id=1` 展示 180 秒运营孪生主线。

## 6. 数据与能力边界

- 全部参赛场景与项目数据为合成数据，不包含客户数据或个人数据。
- 国家包是用于项目策划的官方来源索引，不构成法律意见；具体适用性、现行版本和主管机关要求必须由授权人员确认。
- IFC/GLTF/3D Tiles/GeoJSON/WMS/IoT 为遵循接口形状的合成实例，不宣称为实建模型。
- 黄金主线固定使用确定性模式，确保赛场无网时仍可复现；正常 API 的 OpenAI / 本地模型路由能力保持不变。
- 当前执行工具只生成草案，绝不自动对外发送或更改运营资产状态。
