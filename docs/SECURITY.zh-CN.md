# 安全基线

## 原则

- 将上传的文档视为不可信数据，绝不能当作系统指令。
- 对工具调用实施白名单与最小权限原则。
- 按授权策略隔离不同项目/租户的访问权限。
- 对合同类、监管类、付款类、进度承诺类、安全停工类以及对外函件类行动，强制要求人工审批。
- 保留证据的来源可追溯性与审计上下文。
- 绝不将密钥放入提示词（prompt）、日志或演示文件中。

## 生产环境待办事项

- SSO / OIDC / SAML + 多因素认证（MFA）
- RBAC + ABAC
- 行级租户/项目安全隔离
- KMS 支持的密钥加密
- 带签名的审计日志链
- 上传文件恶意软件扫描
- 数据防泄漏（DLP）与敏感数据分类
- 提示词注入（prompt-injection）测试套件
- CSP / HSTS 与完整的 API 速率限制
- SIEM 集成
- 备份/恢复演练
