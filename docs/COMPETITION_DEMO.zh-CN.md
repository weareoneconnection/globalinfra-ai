# 五分钟竞赛演示路线

## 0:00-0:30 - 问题

海外交通项目需要跨语言、跨合同、跨标准、跨当地法规以及碎片化的项目记录来运作。重要的工单解决缓慢，且难以审计。

## 0:30-0:55 - 产品

GlobalInfra AI 把现场问题和业主函件转化为有证据支撑、受管控的行动。

## 0:55-1:15 - 可验证的演示起点

打开 `/competition`，创建评委专属的合成隔离会话，并指出 TTL、会话 ID 与五个不同角色主体。

## 1:15-3:35 - 主线实时演示

依次完成创建、分析、项目经理审批、HSE 会签、执行、独立核验和关闭七个明确步骤。每个治理步骤都展示主体、内容摘要与签名回执，最终展示完整证据链和 `DRAFT_ONLY_NOT_SENT` 状态。

## 3:35-4:10 - 技术差异化

展示知识网络、证据关系图、受策略约束的智能体与独立核验能力。

## 4:10-4:35 - 防篡改与职责分离证明

说明角色票据不能跨会话使用、五个主体不得复用，且输入、产物或回执被改动后无法核验或关闭。证明来自自动化回归，不要篡改现场会话制造通过效果。

## 4:35-5:00 - 证据与规模化

展示签名发布状态和评测产物，再以国家包、领域包和区域数据面收口。若产物未签名或 commit 不一致，必须保留 `UNVERIFIED` 并解释原因。

## 附加环节（可选）- 全链路中英文切换

在浏览器设置中切换首选语言（或使用顶部导航栏的语言切换按钮），刷新任意页面，展示界面文案、工单数据、智能体名称与领域模型会整体切换为对应语言，且 URL 路径保持不变。
