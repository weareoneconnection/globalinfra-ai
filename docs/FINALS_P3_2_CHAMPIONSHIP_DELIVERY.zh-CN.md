## 可重复生成的终评手册

从已部署、经版本核验的公开 P2 决赛 API（\`GET /competition/finals/overview?lang=zh\`）取得 JSON，保存到**本地临时目录**。不要抓取或公开租户 ROI、签名密钥、真实工程原文。

\`\`\`sh
python evals/p3_2_championship_pack.py \
  --overview /secure/finals-overview-zh.json \
  --commit "$(git rev-parse HEAD)" \
  --output-dir /secure/p3-2
\`\`\`

产出：\`championship-pack.json\` 和 \`championship-rehearsal.md\`。
当前脚本仅输出 \`REHEARSAL_PACK_ONLY\`，发布门禁永远保持 CLOSED。未知/超出边界的业务结论一律**失败关闭**。
执行必须锁定**实际部署的 Commit**，不能拿当前源码 SHA 冒充线上 SHA。
\`signed_release_matches_commit\` 只证明**声明的 API 签名状态 + commit 前缀一致**，真正受信发布仍需审查签名公钥、Digest、Railway 运行镜像及有效的完整证据链；此编译器并不代替验签。

## 终评叙事策略

核心定位：**面向海外基础设施建设的证据驱动、人工治理式 AI 工程协同平台**。

严格围绕一条场景主线：
1. 海外工程业主函件有复杂的语言、专业、属地和责任界面。
2. 多语言接入 + 证据检索/区域适配，来源必须可审计。
3. 专业智能体组队组织分析、提出可追溯建议。
4. 人类审批、执行、独立核验、签名回执；只结束“函件草稿工作流”。
5. 技术展示以经过 CI/签名核实的结果为证据，合成数据与真实成效分层。
6. MY→AE 是架构可配置对照，商业推广依赖真实伙伴和当地专家。
