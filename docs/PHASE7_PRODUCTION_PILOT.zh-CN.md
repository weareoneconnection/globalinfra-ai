# 阶段 7：生产试点

GlobalInfra AI V3.0 将阶段 6 数字孪生产品升级为生产试点运行平面。仓库不会虚构客户身份租户、供应商凭据或真实模型文件，而是提供这些系统接入时必须遵守、可测试的契约。

## 7.1 可信执行

主张与证据生成受管控行动意图。审批只解锁执行，不代表执行成功。关闭前必须具备内容寻址产物、执行回执和独立核验回执。

## 7.2 身份与授权

`AUTH_MODE` 支持 `disabled`、`api_key` 和 `oidc`。OIDC 通过签发方 JWKS 验证 JWT，并将组织、角色和项目范围标准化为 `Principal`。生产变更接口执行 RBAC；请求 ID 与租户级审计事件记录每一次变更。服务端渲染 Web 层可使用独立服务凭据，浏览器/API 客户端使用 OIDC Bearer Token。公开演示默认 `disabled`，生产环境必须使用 `oidc`。

## 7.3 现场作业

`/field` 是离线优先 PWA 工作台。现场观察保存在 IndexedDB，通过幂等客户端 ID 批量重试同步。照片、视频和语音证据在设备端计算摘要，原始二进制文件需要配置对象存储。每条同步观察都会生成受管控工单，并可关联稳定 Twin ID。

## 7.4 真实孪生数据源

数据源注册支持 IFC、glTF、3D Tiles、GeoJSON、WMS 和 IoT 引用，并记录版本、坐标系、摘要及元数据。注册接口不会假装已经转换客户模型；实际部署通过转换/流式服务接入，同时保持 Twin ID 契约稳定。

## 7.5 企业连接器

连接器目录覆盖 Primavera P6、Autodesk Construction Cloud、SharePoint、SAP/Oracle、ArcGIS/GeoServer 和 MQTT/BMS/SCADA。所有适配器统一转换为 `external_id`、`object_type`、`updated_at`、`payload`。系统拒绝把凭据保存到连接器 JSON；凭据必须来自部署密钥管理器。Webhook 使用 HMAC 签名。

## 7.6 AI 发布门禁

模型评测记录数据集版本、指标、阈值及通过/阻断结果。得分低于声明阈值时发布门禁自动关闭。这与现有确定性回退、敏感数据本地路由和证据驱动工作流共同构成 AI 治理。

## 7.7 运行与安全

API 提供 `/livez`、`/readyz` 和 Prometheus 兼容 `/metrics`；所有响应带请求 ID；运行时具备基础限流和变更审计。Kubernetes 分离存活/就绪探针。CI 覆盖 API 测试、评测、迁移、依赖一致性、Web 生产构建和全栈冒烟测试。

## 生产启用清单

1. 设置 `AUTH_MODE=oidc` 及签发方、受众和声明映射。
2. 为现场媒体配置对象存储和病毒扫描。
3. 在密钥管理器中配置连接器凭据，禁止写入连接器 JSON。
4. 用客户受控 URI 替换样例孪生数据源。
5. 运行 AI 评测并要求发布门禁全部打开。
6. 将 `/metrics` 与应用日志接入企业可观测平台。
7. 上线前完成数据库备份恢复与安全事件演练。
