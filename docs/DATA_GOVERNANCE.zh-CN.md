# 数据治理

仓库仅使用模拟数据，包括 V2.0 的全部数字孪生几何引用、传感器读数与仿真场景。

生产环境策略应按以下维度对数据进行分类：

- 租户与项目；
- 司法辖区；
- 保密级别；
- 个人数据状态；
- 客户/雇主限制；
- 出口/跨境限制；
- 保留期限。

推荐架构：全局元数据保存在控制面，敏感项目内容在合同或法律要求的情况下，保留在指定的区域数据面中。

## 数字孪生治理

- `Twin ID` 必须稳定且与数据源无关；来源系统 ID 仅作为别名。
- 每次状态迁移必须记录来源、生效时间、证据和置信度。
- 模型版本、坐标参考系和几何引用必须作为显式元数据。
- 遥测数据具有时间边界，绝不能静默覆盖工程设计真值。
- AI 仿真与实际状态严格分离；只有经审批的行动才能产生运营变更。
- 生产使用前，必须在对象、文件、遥测与场景边界执行项目/租户授权。
