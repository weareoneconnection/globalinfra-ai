# 国家包与可治理知识网络 V4.1

## 产品边界

国家包不是法律意见生成器，而是海外工程项目的属地交付控制面。它将语言、术语、主管机关、许可关口、官方来源、数据策略和人工审批边界绑定到项目与全生命周期。

任何涉及法规解释、许可适用性或对外合同立场的结论，都必须由主管机关、项目授权人或合格的当地专业人员复核。

## 数据链路

```text
项目国家代码
  → 国家包版本
  → 生命周期许可 / 合规关口
  → 官方来源注册表
  → 版本化知识对象
  → 检索相关度 + 引用回执
  → 工单主张 / 分析 / 行动 / 独立核验
```

## 核心接口

- `GET /country-packs`：国家包组合与完整度。
- `GET /country-packs/{code}`：主管机关、许可矩阵、术语、策略与项目绑定。
- `GET /country-packs/{code}/applicability`：按生命周期阶段筛选适用性检查项。
- `GET /knowledge/stats`：知识覆盖、来源与版本状态。
- `GET /knowledge/search`：按国家、分类、阶段与状态进行确定性 TF-IDF 检索。
- `GET /knowledge/{id}`：知识正文与引用回执。

## 引用回执

每个知识对象最少携带：`source_ref`、国家代码、版本、状态、内容 SHA-256、来源 URL、复核日期、生命周期阶段和保密级别。AI 输出引用这些字段，不直接把模型答案当作法规事实。

## 当前示范覆盖

- 马来西亚：DOSH、CIDB、地方审批路径。
- 印度尼西亚：OSS 风险分级许可、PBG / SLF、工程安全路径。
- 沙特阿拉伯：Saudi Building Code、Balady、市政与人员安全路径。
- 阿联酋：MOHRE、Civil Defence、酋长国属地许可与 NOC 路径。

项目业务数据为合成数据；官方链接仅作为来源定位，部署到真实项目之前仍需属地法律、技术和主管机关复核。
