## 提交边界

- 本提交包不捆绑 Node.js 或 Python 第三方包二进制，仅提供项目材料和复现说明。
- 仓库代码不导入、不调用、不暴露其他私有产品的源代码、协议、截图、品牌、域名或凭据。
- 系统展示的 IFC、GLTF、3D Tiles、GeoJSON、WMS 和 IoT 实例均为合成互操作示例，不是第三方项目模型。
- 官方法规链接只作为公开来源索引，不构成法律意见；真实项目必须由属地专业人员复核。
- 对外发布源代码或镜像前，应生成完整传递依赖 SBOM，保留许可证文本与必要 NOTICE，并单独复核 LGPL 组件的分发方式。

## 复核依据

- Web 版本与许可证：`apps/web/package-lock.json`
- Web 直接依赖范围：`apps/web/package.json`
- API 固定版本：`services/api/requirements.txt`
- Python 已安装元数据：`services/api/.venv` 中的包元数据，仅用于本次版本核验
