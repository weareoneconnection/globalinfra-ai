# GlobalInfra AI AI出海赛道提交包

本目录对应 V4.3 参赛提交版。黄金主线为马来西亚轨道项目高处作业事件；V4.3 新增智能助手默认入口、受约束对话智能体和大模型受控起草回复。

## 提交文件

1. `final/GlobalInfra_AI_AI出海应用设计报告.docx`：按官方七章模板编制的可编辑设计报告。
2. `final/GlobalInfra_AI_AI出海应用设计报告.pdf`：与 DOCX 同版的提交版 PDF。
3. `02_五分钟演示脚本与分镜.md`：300 秒录屏脚本、操作路径和故障备选镜头。
4. `03_证据真实性与数据边界清单.md`：真实能力、合成数据、公开来源和待验证事项分层。
5. `04_模型与算法评测报告.md`：30 条数据集、指标、门禁、结果和局限。
6. `05_一键复现与开源说明.md`：环境、命令、CI、依赖和安全配置。
7. `06_最终提交检查表.md`：平台提交、报告、录屏、知识产权和脱敏检查。
8. `07_参赛版本发布说明.md`：版本冻结范围、提交证据和剩余人工填写项。
9. `08_第三方组件清单.md`：直接依赖、锁定版本、许可证与对外分发边界。
10. `final/FINAL_SUBMISSION_MANIFEST.json` 与 `final/SHA256SUMS.txt`：提交包清单和逐文件校验值。
11. `final/GlobalInfra_AI_交融杯_AI出海赛道_提交包.zip`：可直接复核和上传的归档包。

- 团队负责人及成员
