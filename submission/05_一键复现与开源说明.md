# 一键复现与开源说明

## 环境要求

- Docker Desktop 和 Docker Compose
- Git
- 可选的 OpenAI 兼容 API Key 或本地 Ollama
- 默认确定性模式不需要模型额度

## 启动

```bash
cp .env.example .env
docker compose up --build
```

访问：

- 智能助手（默认首页）：`http://localhost:3000`
- 指挥中心全景：`http://localhost:3000/overview`
- API 文档：`http://localhost:8001/docs`
- 健康检查：`http://localhost:8001/health`
- 参赛黄金主线：`http://localhost:3000/competition`
- 180 秒演示：`http://localhost:3000/showcase?project_id=1`

## 评测与测试

```bash
python evals/run_eval.py
python evals/run_intake_eval.py
python evals/run_competition_eval.py
python evals/run_agent_org_eval.py
python evals/run_dispatch_eval.py
python -m pytest services/api/tests -q
```

## 合成测试资料

`data/demo/malaysia-rail-test-pack` 提供 8 份虚构的马来西亚铁路项目函件、指令和记录（DOCX、PDF、TXT 及无文字层扫描件），以及列明预期结果的测试说明，可直接在智能助手中上传测试。

## 本地模型

```bash
ollama pull qwen3:8b
docker compose -f docker-compose.yml -f docker-compose.local-llm.yml up --build
```

### 切换为 DeepSeek 等国内大模型

DeepSeek、通义千问等国内大模型提供 OpenAI 兼容接口，在 `.env` 中修改以下三项即可切换，无需改代码（以 DeepSeek 为例，接口地址和模型名以服务商文档为准）：

```bash
LLM_MODE=openai
OPENAI_COMPAT_BASE_URL=https://api.deepseek.com/v1
OPENAI_COMPAT_MODEL=deepseek-chat
```

`OPENAI_COMPAT_API_KEY` 填写服务商发放的密钥。本次参赛测试使用的是本地 Qwen3-8B 和 OpenAI GPT 系列，DeepSeek 等云端模型尚未纳入测试。

真实密钥只能通过环境变量或部署密钥注入，不得写入仓库、报告、截图或录屏。`restricted` 数据必须保留在本地或批准区域。

## 目录说明

| 路径 | 内容 |
| --- | --- |
| `apps/web` | Next.js 前端和移动 PWA |
| `services/api` | FastAPI、领域模型、工作流和数据库迁移 |
| `packages/country-packs` | 四国国家包与术语策略 |
| `packages/domain-packs` | 铁路 公路 桥梁 隧道 港口 机场领域包 |
| `evals` | 五套可执行评测，含 30 条 AI 出海、12 条智能体组织和 15 条总调度数据集 |
| `infra` | Docker Kubernetes Terraform 参考部署 |
| `docs` | 架构 安全 治理 孪生和竞赛说明 |

## 知识产权和第三方依赖

GlobalInfra AI 是独立代码库，不依赖其他私有产品运行时。直接依赖版本见 `apps/web/package.json`、`apps/web/package-lock.json` 和 `services/api/requirements.txt`。提交前应确认仓库许可证、依赖许可证和参赛单位的对外开源范围；如不计划公开全部代码，可提交可复现演示包和必要的来源说明，但不得把第三方代码重新声明为自有成果。

## 生产边界

当前仓库适用于竞赛演示和受控试点基础。生产上线仍需客户 SSO MFA、租户级数据隔离、KMS、DLP、恶意文件扫描、SIEM、备份恢复演练、漏洞管理和属地法律复核。
