## V5.0 新增

| 能力 | 说明 |
| --- | --- |
| 总调度智能体 | 一句话拆成最多四步，交给七个子智能体并行执行；计划经数据库和会话核实，越界退回规则 |
| 实时调度时间线 | 服务器推送每步状态；两步以上由模型汇总，只能引用步骤和返回来源 |
| 会话记忆 | 当前案例和项目保存在服务器，“这个案例”可接续；智能体问题可在对话中回答 |
| 智能体组织 2.0 | 智能体卡片、动态组队、只读工具、结构化结论、协调与提问、合并计划和核验；分析耗时由约 68 秒降至 18 至 27 秒 |
| 现场作业 2.0 | 一键上报、语音和照片证据校验存储、构件扫码与定位、上报进入智能体组织，风险只调高不调低 |
| 评测 | 新增智能体组织 12 条、总调度 15 条确定性评测，已加入 CI |

## V4.3 新增

| 能力 | 说明 |
| --- | --- |
| 智能助手 | 默认入口，文字或附件发起任务，五个快捷任务 |
| 受约束对话智能体 | 大模型在六个固定工具中选择，越界退回规则 |
| 有出处的法规问答 | 逐句引用，可展开条文、主管机关、版本和官方链接 |
| 大模型起草回复函 | 全部审批后起草，引用须属于工单证据，经独立核验 |
| 项目归属确认 | 无法识别项目时由用户确认，系统不猜测 |
| 缺陷修复 | 限流返回 429 而非 500；函件标题取主题行 |

## 发布边界

本发布包不包含真实客户数据、个人数据、API Key 或私有产品代码。项目和数字孪生数据为合成演示数据；法规链接是公开来源索引；效率收益尚未经过真实项目基线验证。

## 仍需人工完成

1. 填写参赛单位、负责人、成员和报名编号。
2. 根据五分钟分镜录制并审看最终视频（含总调度和现场一键上报镜头）。
3. 复核依赖许可证和单位对外开源范围。
4. 在大赛平台提交并保存回执。
5. 按公司通知完成备案。
