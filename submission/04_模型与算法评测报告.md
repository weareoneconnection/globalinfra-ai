# 模型与算法评测报告

## 评测目的

评测用于验证 AI 出海黄金主线的结构化路由、知识检索、拒答和离线降级是否稳定。它不是客户项目验收，也不用于推断真实世界总体准确率。

## 数据集

- 版本：`ai-outbound-2026.10.14-v1`
- 位置：`services/api/evals/competition_outbound.jsonl`
- 总量：30 条
- 分布：多语事件 8、法规许可 8、合同索赔 6、属地 HSE 4、数字孪生运营 4
- 数据性质：人工设计的合成用例，不含客户或个人数据

## 方法

每条用例运行确定性接入和实时 TF IDF 知识检索。评测器比较国家、生命周期、风险、工单类型和预期证据；无证据用例要求系统拒答；所有结果检查 schema 和离线降级。单案例任一必要字段失败即判定该案例失败，发布门禁要求全案例通过率为 100%。

## 智能助手的验证方式

| 验证项 | 方法 | 当前状态 |
| --- | --- | --- |
| 工具选择受约束 | 越界工具名、不存在的工单号或项目编号退回规则 | 自动化测试通过 |
| 法规回答有出处 | 未引用或引用未检索来源的回答被丢弃 | 自动化测试通过；线上核查回答逐句引用 |
| 改写查询不漏检 | 原话与改写查询合并检索 | 回归测试通过 |
| 不代为执行 | 审批、执行、核验、关闭不在工具清单 | 线上核查：要求代为批准时只列出待审批 |
| 回复函引用合规 | 引用须属于本工单证据，否则退回模板 | 自动化测试通过；线上合成函件核验 6 项全部通过 |
| 敏感数据不出本地 | restricted 数据禁止云端路由 | 自动化测试通过 |
| 调度计划受约束 | 子智能体枚举，案例号、项目和问题编号核对数据库和会话，越界整体退回规则 | 总调度 23 项自动化测试和 15 条评测通过 |
| 汇总不编造 | 只能引用步骤标签和返回来源，否则逐步列出 | 自动化测试通过；线上核查汇总引用通过校验 |

## 自动化门禁

`python evals/run_competition_eval.py`、`run_agent_org_eval.py` 和 `run_dispatch_eval.py` 在 GitHub Actions API job 中执行。除此之外，CI 还运行 API 测试、基础分类评测、接入评测、Web 构建、Alembic 迁移与模型一致性检查，以及 Docker Compose 全栈烟测。任一门禁失败会阻止 CI 成功。

## 局限和下一轮评测

- 样本量小且由开发团队设计，存在覆盖偏差。
- 当前结果主要验证确定性路径，不代表不同大模型和语言上的泛化性能。
- 检索知识库为受控种子数据，真实项目文档噪声和版本冲突尚未纳入。
- 尚未完成独立评审者双盲标注和一致性统计。
- 大模型的调度规划、智能体结论和回复起草尚无人工标注集。目前由自动化测试（模型输出以桩函数模拟，验证枚举、数据库核实、引用校验和退回规则）、两套规则模式评测及 2026 年 10 月 15 日的线上人工核查验证。
- 下一轮应使用不少于 50 条获授权的真实脱敏事件，报告精确率、召回率、F1、拒答校准、人工一致性、P50 P95 延迟、令牌成本和错误类别。
