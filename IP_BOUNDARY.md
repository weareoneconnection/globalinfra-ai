# GlobalInfra AI - IP Boundary

GlobalInfra AI is structured as an independent codebase with its own branding, domain model, workflow definitions, schemas, UI, deployment assets, and demo data.

This repository must not:

- import TheOne packages;
- call TheOne APIs;
- include TheOne source code;
- include TheOne private protocol names;
- include TheOne screenshots, branding, domains, or credentials;
- include sensitive project/client data.

The competition dataset in `data/demo/` is synthetic. Replace only with approved, sanitized data.
